# Разведчик будущего — CLAUDE.md

Персональный ИИ-агент ежедневного мониторинга: собирает новости за 24 часа по темам ИИ, управления и строительства, фильтрует через Claude и отправляет структурированный дайджест в Telegram в 5:00 МСК. Работает автономно через GitHub Actions без сервера.

---

## Структура проекта

```
TG-bot-test/
├── agent_new.py          # Основной бот (активная версия)
├── agent.py              # Старая версия (резерв, не запускается)
├── context.json          # Профиль пользователя — редактировать здесь
├── db.sqlite3            # База дедупликации (создаётся автоматически)
├── requirements.txt      # Python-зависимости
├── .env                  # API-ключи (не в git)
├── .gitignore
├── idea.md               # Концепция и спецификация бота
└── research.md           # Исследование аналогов и архитектурные решения

../.github/workflows/
└── daily_digest.yml      # GitHub Actions — единственный активный scheduler
```

> Папка `TG-bot-test/.github/workflows/` GitHub Actions **не видит** — работает только корневой `.github/workflows/`.

## Tech Stack

| Компонент | Что используется | Зачем |
|---|---|---|
| Язык | Python 3.11 | Async-поддержка, простота |
| Сбор данных | Tavily API | Веб-поиск с фильтром по дате (days=1) |
| Синтез | Claude Sonnet 4.6 (Anthropic) | Генерация дайджеста на русском |
| Доставка | python-telegram-bot | Async отправка в Telegram |
| Дедупликация | SQLite (stdlib) | Хранение виденных URL, 30 дней |
| Планировщик | GitHub Actions (cron) | Запуск в 02:00 UTC = 5:00 МСК |
| Секреты | GitHub Secrets + .env | Ключи не в коде |

## Архитектура

```
GitHub Actions (cron 02:00 UTC)
        │
        ▼
  agent_new.py
        │
        ├─── load_context()     ← context.json (профиль пользователя)
        │
        ├─── init_db()          ← db.sqlite3 (дедупликация)
        │
        ├─── collect_news()
        │         └── Tavily API × 19 запросов
        │               └── фильтр is_seen() → mark_seen()
        │
        ├─── generate_digest()
        │         └── Claude API (claude-sonnet-4-6)
        │               └── промпт из context.json + статьи
        │
        └─── send_to_telegram()
                  └── Telegram Bot API
                        └── 7 сообщений × asyncio.sleep(0.8)
```

## 5 ключевых решений

| # | Решение | Почему |
|---|---|---|
| 1 | **Один вызов Claude** вместо мультиагентов | Цепочка агентов = сложность без выгоды; один промпт дешевле и надёжнее |
| 2 | **`---BLOCK---` разделитель** в ответе Claude | Позволяет отправлять 7 отдельных Telegram-сообщений без парсинга |
| 3 | **SQLite для дедупликации** (не Redis, не файлы) | Stdlib Python, 0 зависимостей, 30 дней хранения, < 1 МБ |
| 4 | **context.json** вместо захардкоженного профиля | Пользователь меняет проекты/приоритеты без касания кода |
| 5 | **GitHub Actions** вместо VPS | Бесплатно, без сервера, автоматический перезапуск при ошибке |

## Тестирование

**Локальный запуск:**
```bash
cd TG-bot-test
python agent_new.py
```

**Ручной запуск в GitHub Actions:**
```bash
gh workflow run daily_digest.yml
```

**Чек-лист проверки:**
- [ ] В Telegram пришло 7 отдельных сообщений (не одно)
- [ ] Первое сообщение — шапка с датой (`📡 РАЗВЕДКА: ДД.ММ.ГГГГ`)
- [ ] Последнее сообщение — `🧠 ГЛАВНАЯ ИДЕЯ ДНЯ`
- [ ] При повторном запуске в тот же день — меньше статей (дедупликация работает)
- [ ] В консоли: `Новых статей: N, пропущено (дубли): M`

## Самообновление

Механизм адаптации бота без изменения кода:

| Что меняется | Где менять | Эффект |
|---|---|---|
| Мои проекты и приоритеты | `context.json` → `current_projects`, `focus_now` | Следующий дайджест учтёт изменения |
| Что исключить из дайджеста | `context.json` → `avoid` | Claude перестанет включать эти темы |
| Темы поиска | `agent_new.py` → `SEARCH_QUERIES` | Добавить/убрать поисковые запросы |
| Время запуска | `.github/workflows/daily_digest.yml` → `cron` | Расписание меняется (формат UTC) |
| Структура дайджеста | `agent_new.py` → `generate_digest()` → промпт | Добавить/убрать блоки |

**Текущее расписание:** `0 2 * * *` = 05:00 МСК
