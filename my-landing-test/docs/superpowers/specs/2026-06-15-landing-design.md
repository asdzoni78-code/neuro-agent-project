# Лендинг "Система вместо хаоса" — Design Spec

> **For agentic workers:** Use superpowers:writing-plans → superpowers:executing-plans to implement this spec task-by-task.

**Goal:** Одностраничный лендинг-портфолио цифрового специалиста по автоматизации бизнес-процессов.

**Architecture:** Один файл `index.html` с встроенными `<style>` и `<script>`. Никаких зависимостей кроме Google Fonts через CDN. Статика, открывается в браузере без сервера.

**Tech Stack:** HTML5, CSS3 (custom properties, CSS Grid, scroll-driven animations), Vanilla JS (IntersectionObserver, custom cursor, count-up)

---

## 1. Целевая аудитория и цель сайта

**Аудитория:** Владельцы малого бизнеса в РФ (розница, услуги, опт, сервис). Не технари. Имеют хаотичные ручные процессы — заявки в WhatsApp, данные в Excel, всё в голове.

**Цель сайта:** Одна — получить сообщение в Telegram. Не продать, не объяснить технологии. Просто начать разговор.

**Тон:** Уверенный, конкретный, человеческий. Говорим о боли клиента, не о своих технологиях.

## 3. Визуальная система

### Цветовая палитра — "Midnight Electric"

```css
--bg:         #080B14   /* основной фон */
--surface:    #0F1420   /* карточки, секции */
--border:     #1E2D40   /* бордеры */
--accent:     #3B82F6   /* электрик-синий, только CTA */
--glow:       rgba(59,130,246,0.35)
--text:       #E2E8F0   /* основной текст */
--muted:      #64748B   /* второстепенный текст */
```

### Типографика — Golos Text (Google Fonts)

```
H1 герой:  clamp(3.5rem, 10vw, 8rem) · weight 900 · letter-spacing -0.03em
H2:        clamp(2rem, 5vw, 3rem)    · weight 700
H3:        1.25rem                   · weight 600
Body:      1rem / line-height 1.7    · weight 400
Метки:     0.75rem · uppercase · letter-spacing 0.1em · цвет --muted
```

### Компоненты

**Navbar:** pill-форма (`border-radius: 100px`), `position: fixed; top: 16px`, `backdrop-filter: blur(24px)`, glassmorphism фон `rgba(8,11,20,0.7)`, бордер `rgba(255,255,255,0.06)`. Содержит: логотип слева, CTA-кнопка справа.

**Кнопки CTA:** `border-radius: 8px`, `padding: 14px 32px`, `background: var(--accent)`, hover → `box-shadow: 0 0 20px var(--glow)` + `translateY(-2px)`.

**Bento-карточки:** `border-radius: 20px`, `border: 1px solid var(--border)`, `background: var(--surface)`, hover → `translateY(-4px)` + `border-color: rgba(255,255,255,0.12)`.

**Glass-карточки (кейсы):** `background: rgba(15,20,32,0.6)`, `backdrop-filter: blur(20px)`, `border: 1px solid rgba(255,255,255,0.08)`, `inset 0 1px 0 rgba(255,255,255,0.1)`.

**Фоновые orbs:** 2 div `position: fixed`, `border-radius: 50%`, `filter: blur(80px)`, `opacity: 0.08`, `background: var(--accent)`, `pointer-events: none`.

### Анимации

- **Scroll-reveal:** `animation-timeline: view()`, `animation-range: entry 0% entry 30%`, keyframe `fade-up` (opacity 0→1, translateY 40px→0). Fallback через IntersectionObserver для Safari.
- **Progress bar:** `3px` синяя полоска `position: fixed; top: 0`, `animation-timeline: scroll(root block)`, `transform-origin: left`, keyframe `grow-x` (scaleX 0→1).
- **Count-up:** Цифры в блоке героя считают от 0 до конечного значения за 1.5s при первом появлении в viewport (IntersectionObserver).
- **Custom cursor:** `div.cursor` 12px круг, `mix-blend-mode: difference`, следует за мышью через JS. На hover по ссылкам/кнопкам — scale(2.5). Скрыт на touch-устройствах.

### Адаптивность

```
Desktop:  > 1200px  — полный bento-grid, все эффекты
Tablet:   768-1200px — bento 2 колонки
Mobile:   < 768px  — одна колонка, navbar без pill-формы, cursor отключён
```

## 4. Структура страницы и контент


### БЛОК 1 — ГЕРОЙ

**H1 (кинетическая типографика, появляется побуквенно):**
```
СИСТЕМА
ВМЕСТО ХАОСА
```

**Подзаголовок:**
> Разбираю один ручной процесс в вашем бизнесе и собираю под него простой рабочий инструмент: мини-CRM, бота, форму или дашборд.

**CTA:** `[Обсудить проект →]` → `https://t.me/yourusername`

**Строка доверия (count-up):**
`15+` систем запущено · `1,5` года в автоматизации · ответ за `3` часа

### БЛОК 2 — БОЛЬ

**H2:** Узнаёте себя?

**Список (иконка ✗, появляются по одному при скролле):**
1. Заявки теряются между WhatsApp, почтой и блокнотом
2. Каждый месяц вручную копируете одни и те же данные в таблицы
3. Нет единого места, где видно — что происходит с клиентом прямо сейчас
4. Найм нового сотрудника = месяц хаоса, пока он разберётся
5. Понимаете, что нужно автоматизировать, но не знаете с чего начать

**Переход (курсив, цвет --muted):**
> Всё это — не проблема с дисциплиной. Это отсутствие системы.

### БЛОК 3 — УСЛУГИ (Bento Grid)

**H2:** Что я строю

**Bento-карточки (12-col grid):**

| Размер | Услуга | Подпись |
|--------|--------|---------|
| span 8 (wide) | Мини-CRM | Все клиенты в одном месте. Статус виден за 5 секунд |
| span 4 | Телеграм-бот | Заявки приходят сами, без менеджера на телефоне |
| span 4 | Генератор КП | Готовое предложение за 2 минуты, не за 2 часа |
| span 4 | Фотоотчёт | Клиент получает PDF, вы не тратите вечер |
| span 4, row 2 (tall) | AI-агент | Отвечает на вопросы клиентов 24/7, пока вы спите |
| span 8 | Дашборд | Видите цифры бизнеса, не Excel с 40 вкладками |

**Процесс (3 шага, flex-row):**
`Разбираемся` → `Строим` → `Запускаем`

### БЛОК 4 — КЕЙСЫ + ДОВЕРИЕ

**H2:** Что получилось у других

**3 glass-карточки (кейсы):**

**Кейс 1 — Магазин стройматериалов**
> Менеджеры тратили 3 часа на оформление сделки. Собрал мини-CRM с автозаполнением — теперь 20 минут.
> Метрика: `3 часа → 20 минут`

**Кейс 2 — Фотостудия**
> 40% заявок терялось в переписке. Телеграм-бот принимает запись сам, уведомляет администратора.
> Метрика: `40% потерь → 0%`

**Кейс 3 — Сервисный центр**
> Пять таблиц Excel, которые никто не понимал. Один дашборд с актуальными цифрами в реальном времени.
> Метрика: `5 таблиц → 1 дашборд`

**CTA #2:** `[Хочу так же — написать в Telegram →]`

### БЛОК 5 — КТО Я

**H2:** Кто за этим стоит

**Аватар:** круглый placeholder 120×120px, цвет `var(--surface)`, инициалы "Е" по центру.

> Не продаю «комплексную цифровизацию». Беру один процесс, который болит прямо сейчас — и делаю под него инструмент.

**Строка фактов:**
`1,5 года в автоматизации` · `15+ запущенных систем` · `ответ за 3 часа`

## 6. Что НЕ делаем

- Никаких стоковых фото ноутбуков и рук
- Никакой сложной 3D/WebGL графики
- Никаких 5+ цветов в палитре
- Никакого terminal/hacker стиля
- Никаких внешних JS-библиотек (jQuery, GSAP, etc.)
- Никаких форм с email — только Telegram
