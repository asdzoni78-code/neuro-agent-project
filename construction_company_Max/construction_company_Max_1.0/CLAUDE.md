# CLAUDE.md — «Замеры и перерасход»

Веб-приложение для строительного объекта Максима: прораб вводит размеры помещений в двух стадиях (до/после работ), система считает фактическую толщину материала из разницы замеров и выявляет приписки. AI-агент (Claude Opus) формирует деловой отчёт и отправляет его Максиму в Telegram.

---


## 2. Tech Stack

| Слой | Технология | Почему |
|---|---|---|
| UI | Vanilla JS + HTML/CSS | Без сборки, открывается через file:// |
| Хранение | localStorage (`zamery_v1`) | Без бэкенда и авторизации (пилот) |
| AI | Claude claude-opus-4-8 (Anthropic API) | Генерация делового отчёта о перерасходе |
| Доставка | Telegram Bot API | Два сообщения Максиму (алерт + полный отчёт) |
| API-вызовы | fetch() прямо из браузера | Нет сервера, заголовок `anthropic-dangerous-direct-browser-access: true` |
| Ключи | config.js (gitignored) | `CONFIG.ANTHROPIC_API_KEY`, `TG_BOT_TOKEN`, `MAKSIM_CHAT_ID` |

## 4. Пять ключевых решений

| # | Решение | Почему |
|---|---|---|
| 1 | Толщина из разницы размеров | Единственный способ поймать «заложили 10, сделали 8, записали 10» — ни один конкурент (Gectaro, HeavyJob, Raken) это не делает |
| 2 | Нет фреймворков, нет сборки | Открывается через `file://` без npm install — порог входа ноль |
| 3 | localStorage без бэкенда | Пилот для одного объекта; данные на компьютере Александра |
| 4 | config.js в .gitignore | API-ключи не попадают в git ни при каком раскладе |
| 5 | Два TG-сообщения (алерт + полный) | Первое — быстрый сигнал, второе — детали; Максим видит главное без прокрутки |

## 8. Самообновление файлов

| Файл | Кто меняет | Триггер |
|---|---|---|
| `app.js` → `localStorage` | Сам при любом вводе | `input` / `change` событие → `save()` → `renderAll()` |
| `ai-agent.js` → отчёт | Александр нажимает кнопку | `click` → читает localStorage → вызывает API → рендерит в модалку |
| `config.js` | Только вручную | При получении нового ключа или смене TG chat_id |
| `CLAUDE.md` | Только вручную в сессии | После архитектурных изменений |

**localStorage-ключ:** `zamery_v1`  
**Структура state:** см. SPEC.md раздел «Данные»  
**Реактивность:** любой `input` → `calcProject()` → `save()` → `renderComparison()` — без кнопки «Сохранить»
