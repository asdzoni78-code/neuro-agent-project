# Идея: «Замеры и перерасход» — пилот стадии 1-2
_Последнее обновление: 01.07.2026_

---

## Суть

Веб-приложение для одного строительного объекта Максима.
Прораб вносит реальные размеры помещения на двух стадиях — система сама считает площади поверхностей, толщину слоя и расход материала. Сравнивает с заложенной сметой.

**Главная боль:** «заложили 10 см, сделали 8, записали 10» — становится видно, с ответственным.

---

## Для кого

- **Прораб** — вводит размеры с телефона на каждой стадии
- **Максим** — видит план / факт / смету и ответственного с ноутбука/планшета

---

## Две стадии

| | Стадия 1 | Стадия 2 |
|---|---|---|
| Когда | После демонтажа (до работ) | После стяжки / штукатурки |
| Цель | Замер для закупки | Контроль факта |
| Что вводит прораб | Размеры помещения + плановую толщину по каждой поверхности | Размеры помещения снова |
| Что система считает | Площади + расход по плану | Фактическую толщину из разницы размеров + расход факт |

---

## Геометрия помещения

Помещение — набор поверхностей. У каждой своя площадь и своя толщина материала.

### Размеры помещения (вводятся на каждой стадии, в мм)
- **Высота** — от чернового пола до потолка
- **Длина** — расстояние между стенами А и В (противоположные)
- **Ширина** — расстояние между стенами Б и Г (противоположные)

---

### Пол
- Площадь = ширина × длина (в м²)
- Материал: Стяжка ЦПС
- Толщина стадия 1: вводит прораб (план)
- Толщина стадия 2: **система считает** = высота_ст1 − высота_ст2

---

### Потолок
- Площадь = ширина × длина (совпадает с полом; отдельный ввод если отличается)
- Материал: **заглушка** в пилоте (поле есть, но не активно — не влияет на расчёт)
- Толщина: **заглушка** в пилоте, не считается

---

### Стены А, Б, В, Г (каждая отдельно)

**Расстановка стен:**
- А и В — противоположные (расстояние между ними = Длина комнаты)
- Б и Г — противоположные (расстояние между ними = Ширина комнаты)

**Площадь нетто каждой стены:**
```
площадь_нетто = высота_стены × ширина_стены − Σ(ширина × высота каждого проёма)
```

**Проёмы на каждой стене** (привязаны к конкретной стене):
- Окна: ширина × высота (одно или несколько)
- Двери: ширина × высота (одна или несколько)

**Высота стены** — зависит от порядка работ:
- Стяжка РАНЬШЕ штукатурки → высота_стены = высота_ст2 (от уровня стяжки до потолка)
- Штукатурка РАНЬШЕ стяжки → высота_стены = высота_ст1 (от чернового пола)
- Не указано → используем высота_ст1

**Толщина штукатурки стен:**
- Стадия 1: вводит прораб (план)
- Стадия 2: **система считает усреднённо по паре:**
  - Толщина_пары_АВ = (длина_ст1 − длина_ст2) / 2 → применяется к стенам А и В
  - Толщина_пары_БГ = (ширина_ст1 − ширина_ст2) / 2 → применяется к стенам Б и Г

**Объём штукатурки на стену:**
```
объём = толщина_пары / 2 × площадь_нетто_стены
расход_тонн = объём × норма_кг_м2_см / 1000
```

---

### Откосы (отдельные записи)
- **Откос окна**: метраж (длина) × ширина откоса × толщина
- **Откос двери**: метраж (длина) × ширина откоса × толщина
- В идеале откосы окон одинаковые → одна запись с одной шириной
- Заглушки для разной ширины если нужно (несколько записей)

---

### Колонны (отдельные записи, одна запись = одна колонна)
- Площадь = периметр колонны × высота
- Объём = площадь × толщина штукатурки

---

## Расчёт расхода (общая формула)

```
расход_тонн = площадь_нетто_м² × толщина_см × норма_кг/(м²·см) / 1000
```

- Итого **отдельно** по каждому материалу
- Разные материалы не суммируются

---

## Справочник материалов (редактируемый)

| Поле | Значение |
|---|---|
| Название | Штукатурка гипс. / Штукатурка ЦПС / Стяжка ЦПС / Шпаклёвка / Своя |
| Норма | кг/м²·см |
| Цена | ₽/т |
| Заложено в смете | тонн (глобально на весь объект) |

**Материалы по поверхностям:**
- Пол → Стяжка ЦПС (по умолчанию)
- Стены → Штукатурка гипс. / Штукатурка ЦПС / Своя (выбор при вводе)
- Потолок → заглушка (материал не активен в пилоте)
- Откосы / Колонны → материал из справочника (выбор при вводе)

---

## Единицы

- Размеры: **мм** (пример: высота 3140, ширина 5530)
- Площадь: м² (система конвертирует мм → м²)
- Расход: тонны
- Стоимость: рубли

---

## Экраны (три)

### 1. Объект и помещения
- Список помещений сгруппирован по этажам
- Добавить / редактировать помещение (этаж, название)

### 2. Ввод замера
- Выбрать помещение → выбрать стадию
- **Общие размеры:** высота, длина (А→В), ширина (Б→Г) в мм
- **Порядок работ:** Стяжка раньше / Штукатурка раньше / Не указано
- **Поверхности:**
  - Пол: материал + план.толщина (ст.1) / авто из высоты (ст.2)
  - Потолок: материал + толщина (заглушка)
  - Стены А, Б, В, Г — каждая отдельно:
    - Список проёмов (окна / двери: ширина × высота)
    - Материал
    - Толщина (ст.1: ввод; ст.2: авто из пары)
  - Откосы окон / дверей: метраж, ширина, толщина
  - Колонны: периметр, высота, материал, толщина
- Ответственный
- Фото (заглушка — кнопка без реального хранения)

### 3. Сравнение (главный экран)

| Материал | Смета, т | План (ст.1), т | Факт (ст.2), т | Расхождение, т | Расхождение, ₽ | Ответственный |
|---|---|---|---|---|---|---|

- Перерасход — **красным**
- Разбивка: объект → этаж → помещение → поверхность
- Сводка по объекту

---

## Правила

1. Стадии необязательны: одна = калькулятор, две = сравнение план/факт
2. Итого отдельно по каждому материалу — не суммировать разные
3. Источник правды — замер прораба, система не додумывает геометрию
4. **Всё живое** — любой ввод пересчитывает мгновенно (без кнопки «Сохранить / Пересчитать»)
5. Нормы и цены черновые, редактируемые
6. Хранение: localStorage (без бэкенда, без авторизации)
7. Интерфейс: русский, адаптив телефон + ноутбук

---

## Приёмочные критерии (готово, когда)

- [ ] Помещение с двумя стадиями замеров
- [ ] Пол: площадь из размеров, толщина ст.2 = Δ высоты
- [ ] Стены А/Б/В/Г: площадь нетто (с вычетом проёмов), толщина ст.2 = Δ длины или ширины / 2
- [ ] Порядок работ влияет на высоту стены в расчёте
- [ ] Откосы и колонны: отдельные записи, свои формулы
- [ ] Таблица смета/план/факт/расхождение (т и ₽) по материалам
- [ ] Виден ответственный и помещение где разошлось
- [ ] Разбивка по этажам и помещениям; сводка по объекту
- [ ] Перерасход красным; данные переживают перезагрузку (localStorage)
- [ ] Одна стадия = простой калькулятор
